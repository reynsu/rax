## Summary

The v2 implementation is structurally clean: ISO 25010 mapping is rigorous, the pipeline (deterministic → LLM panel → conformal) composes well, tests are comprehensive (81 passing, 100% coverage on `aggregation.py` + `scoring.py`), and the honesty framing is consistent end-to-end. ## Findings

### CRITICAL
None.

### HIGH

**H-1 — Shell injection via `RAX_OUT_DIR` interpolated into inline `python -c`**
File: `scripts/deterministic_layer.sh:218`

```bash
"$PYTHON" -c "
...
d = json.load(open('$DETERMINISTIC_OUT'))
```

`DETERMINISTIC_OUT` is built from `${RAX_OUT_DIR:-/tmp}` with no sanitization. A caller exporting `RAX_OUT_DIR="/tmp'); import os; os.system('id')  #"` gets arbitrary Python execution. Limited blast radius (attacker must already control the env), but trivial to weaponize in a shared CI runner.
**Fix:** pass the path as a positional argv, not interpolated into the `-c` string.

**H-2 — Monte Carlo inner loop calls Python ~10 000× per category**
File: `scripts/aggregation.py:165–167`

```python
for i in range(n_samples):
    row = {k: float(samples[i, j]) for j, k in enumerate(common)}
    out[i] = self.aggregate_to_category(row, weights)
```

For the linear-utility common case this can be vectorised in numpy (`(samples * w / total_w).sum(axis=1) * 10.0`), already done correctly in `aggregate_intervals_to_overall`. Becomes a CI bottleneck as the corpus grows.
**Fix:** detect "all linear utilities" and take the vectorised path; keep the loop only when sigmoid utilities are present.

**H-3 — `except Exception` swallows YAML parse errors silently**
File: `scripts/scoring.py:217–218`

```python
except Exception:
    _SCALE_MAPPING_CACHE = fallback
```

Catching `Exception` here means a refactor bug inside the `try` is silently treated as "use defaults". Future drift is invisible.
**Fix:** narrow to `(yaml.YAMLError, OSError)` and emit a `logging.warning(...)` so operators see the silent fallback.

### MEDIUM

**M-1 — Untrusted binary execution from project `node_modules/.bin/`**
File: `scripts/deterministic_layer.sh:96, 109, 125, 143`

By design — convenience for projects with locally-pinned ESLint/tsc. Anyone with write access to the audited dir can substitute a malicious binary. Should be gated by `--allow-project-bins` (or `RAX_TRUST_PROJECT_BINS=1`) with a doc warning.

**M-2 — Telemetry endpoint URL has no scheme/host validation**
File: `scripts/telemetry.py:63, 160`

User-supplied `--endpoint` can be `http://192.168.x.x/...` (SSRF to private network) or `file://`-flavored exotica.
**Fix:** require `https://`, optionally block RFC-1918.

**M-3 — Exception strings copied verbatim into output JSON may include key fragments**
Files: `scripts/cross_llm_eval.py:194–195`, `scripts/judge_panel.py:138`

`unavailable[name] = str(exc)` lands in a result file users may share. SDK error messages occasionally embed the key prefix or a redacted form (`sk-ant-***...`) — still informative to an attacker.
**Fix:** scrub known prefixes before stringification (`sk-ant-`, `sk-`, `Bearer `, etc.) → `[REDACTED]`.

**M-4 — Cache key derived from env var; model name acts as path component**
File: `scripts/judge_panel.py:78–80, 97–98`

`_cache_key("$RAX_CLAUDE_MODEL", prompt)` uses the env value as a directory segment. `RAX_CLAUDE_MODEL=../../../tmp/x` writes outside `.cache/judge_panel/`. Cache files also inherit umask.
**Fix:** validate against `^[A-Za-z0-9._-]+$`; pass `mode=0o600` on `write_text`.

**M-5 — Path traversal via `owner/repo` in `mine_corpus.py`**
File: `scripts/mine_corpus.py:270–276`

`(args.output / f"{owner}__{name}.json")` doesn't reject `name="../etc/cron.d/x"`. The script trusts the input list, but the input list is user-editable.
**Fix:** validate `^[A-Za-z0-9_.-]+$` on both halves before path construction.

**M-6 — Conformal coverage measured on the same set used to fit**
File: `tests/test_conformal.py:123–134` (`test_real_calibration_coverage_in_target_band`)

Split-conformal's coverage guarantee is a held-out property. Computing `cov = cz.empirical_coverage(cal)` on `cal` after `cz.fit(cal)` is the in-sample fit, optimistically biased. The test currently green-lights the production CI gate (`validate_calibration.py` calls the same path) — could mask a degraded predictor in the future.
**Fix:** 80/20 split before fit; evaluate on the 20% held-out.

### LOW

**L-1 — No size cap on tool JSON before `json.load()`**
File: `scripts/parse_deterministic.py:176–182`

Semgrep on a large monorepo can emit hundreds of MB. Add a 50 MB cap with a warning rather than silent OOM.

**L-2 — Module-level `_SCALE_MAPPING_CACHE` is a test-isolation hazard**
File: `scripts/scoring.py:189–219`

Hand-rolled global makes it hard to reset between parametrised tests. Consider `@functools.lru_cache` on `_load_scale_mapping` so `cache_clear()` is the documented reset.

### NIT (not blocking)

- `scripts/judge_panel.py:25, 34` imports `asyncio` and `Awaitable` but never uses them — leftover from a planned async path.
- Inconsistent typing style: `tuple[…]` (string-quoted) in `aggregation.py`, `Tuple[…]` in `conformal.py`, `dict[…]` in `scoring.py`. With `from __future__ import annotations` everywhere, the lowercase non-quoted form is the correct pick.
- `judge_panel.py:104` imports `_judge_*` (underscore-private) cross-module — fragile; expose a public registry instead.

## Recommendation

**APPROVE WITH COMMENTS.** Suggested order to address before announcing v2.0 publicly:

1. **H-1** (shell injection) — 5 min fix.
2. **H-3** (broad except) — 2 min fix.
3. **M-3** (exception scrubbing) — 10 min fix; security-relevant for output sharing.
4. **M-6** (test held-out split) — 10 min fix; otherwise the CI gate is rubber-stamping itself.
5. **H-2** (vectorised MC) — 30 min; perf, not correctness.
6. The rest (M-1, M-2, M-4, M-5, L-1, L-2, NITs) can land in a follow-up tagged `v2.0.1`.
